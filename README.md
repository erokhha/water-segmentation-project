# Water Segmentation

Проект по автоматической сегментации водных объектов на спутниковых и аэрофотоснимках с использованием глубокого обучения.

## Модель и данные

Используется **U-Net с энкодером ResNet34**. Модель обучалась на данных OpenEarthMap, CAID, LandCover, xBD, FLAIR, GLH-Water и CoastTrain (NAIP).

Итоговая обучающая выборка содержит **5406 пар изображений и масок**. Поддерживаются два режима обучения: стандартные окна 512×512 и смешанные окна 768/512 с дополнительным пространственным контекстом.

## Технологии

- **Python, PyTorch** — обучение нейросети и инференс.
- **segmentation-models-pytorch** — архитектура U-Net.
- **NumPy, Rasterio, Pillow** — обработка изображений, масок и TIFF.
- **AdamW** — оптимизация модели.
- **IoU, Precision, Recall** — оценка качества сегментации.

## Проверка и продолжение

`python src/train.py --help` показывает обязательные параметры нового продолжения: полный `epoch_XXX.pth`, новое имя запуска, режим `standard` или `mixed`, число эпох, базовую логическую эпоху и веса классов. Для проверки без записи результатов добавьте `--preflight`. Обучение использует batch 1 и `num_workers=0`. Новый запуск фиксирует SHA всех исполняемых модулей `src/training/`; строгий `--resume` старого запуска после изменения кода не предполагается. Для нового запуска используется его собственный checkpoint и неизменившаяся версия кода.

`python src/infer.py --help` показывает аргументы инференса TIFF. Для целого изображения нужны RGB TIFF, полный checkpoint, новый каталог вывода, размер окна 512 или 768, stride и порог. Результат включает карту вероятностей, маску и manifest. Модель создаётся без загрузки начальных ImageNet весов из сети: полный checkpoint загружается с `strict=True`.
