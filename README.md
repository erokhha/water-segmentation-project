# Water Segmentation

Проект по автоматической сегментации водных объектов на спутниковых и аэрофотоснимках с использованием глубокого обучения.

## Модель и данные

Используется **U-Net с энкодером ResNet34**. Модель обучалась на данных OpenEarthMap, CAID, LandCover, xBD, FLAIR, GLH-Water и CoastTrain (NAIP).

Итоговая обучающая выборка содержит **5406 пар изображений и масок**. Поддерживаются два режима обучения: стандартные окна 512×512 и смешанные окна 768/512 с дополнительным пространственным контекстом.

## Технологии

- **Python, PyTorch** — обучение нейросети и инференс.
- **segmentation-models-pytorch** — архитектура U-Net.
- **NumPy, Rasterio, Pillow** — обработка изображений, масок и TIFF.
- **AdamW** — оптимизация модели.
- **IoU, Precision, Recall** — оценка качества сегментации.

## Структура проекта

- `src/model.py` — архитектура модели.
- `src/dataset.py` — базовая обработка данных.
- `src/training/` — подготовка обучающих данных, обучение, метрики и checkpoint.
- `src/train.py` — единый запуск обучения.
- `src/infer.py` — сегментация изображений с окнами 512 или 768.
- `configs/` — разбиения данных и манифесты.

## Результат

Модель формирует вероятностные карты и бинарные маски водных объектов. Поддерживается обработка больших TIFF-изображений с перекрывающимися окнами.

Обученные модели и результаты экспериментов хранятся отдельно в `outputs/`.
