# Пробный Train из 4000 разных пар

Готовый состав для **будущего продолжения выбранного старого checkpoint**. Этот каталог не содержит копий изображений или масок; `train_manifest.csv` ссылается на уже имеющиеся Train-источники. Подготовка не запускала обучение и не меняла принятые веса.

| Источник | Всего пар | Отмечены как трудные |
|---|---:|---:|
| OEM после 36 исключений владельца | 1888 | 962 |
| CAID, только author Train | 1461 | 455 |
| LandCover, без 8 повторов/конфликтов | 69 | 1 |
| xBD, проверенные Train-пары | 54 | 54 |
| FLAIR D013/D034, без резерва и известных спорных меток | 528 | 528 |
| **Итого** | **4000** | **2000** |

`focus_hard=1` означает ошибку выбранного старого checkpoint против **исходной маски** на разрешённом Train: не менее 1000 FP или FN. Для CAID выбраны только сильные пропуски **положительно размеченной** воды с долей воды `[0.05,0.95)` и FP не более 5% кадра. Ошибка модели не подтверждает автоматически правильность исходной маски. В FLAIR выбор ограничен 48 файлами на группу соседних тайлов; 528 файлов относятся к 71 такой группе, а не к 528 независимым съёмкам.

Разные пары здесь не означают все **новые источники**. OEM/CAID/LandCover/xBD уже были допустимы старому маршруту; FLAIR 528 — новые относительно выбранного checkpoint. CAID ID не имеют локального acquisition ID, поэтому независимость его съёмок не доказана. Целевой TIFF, OEM Test, D013 Z18 и D066 в Train не входят. Исходная OEM Validation остаётся прежней, `tyrolw` не переносится.

Подготовительный контроль без обучения:

```bash
conda run -n water-seg python -u src/train_hard_continue.py --preflight
```

Все 4000 реальных RGB–mask пар уже прошли загрузку и проверку формы, типа, классов и конечности значений. Отчёт: `outputs/checks/train_hard_4000_20261029_001/full_loader_check.json`. Preflight строго загружает старые веса и AdamW state, проверяет forward пяти источников и не создаёт обучающий каталог.

Будущий запуск требует отдельного явного выбора числа эпох и **нового** имени каталога. Команда имеет вид `conda run -n water-seg python -u src/train_hard_continue.py --run ИМЯ --epochs ЧИСЛО`; без этих аргументов обучение не стартует. Для испытания улучшения понадобится отдельный парный контроль, а не только результат этого Train. Текущий runner сохраняет checkpoint каждой завершённой эпохи, но автоматическое точное продолжение прерванной эпохи не реализует; это ограничение нужно учитывать до долгого запуска.
